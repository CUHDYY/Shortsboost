Setup checklist

  1. Enable YouTube Data API v3 and YouTube Analytics API in Google Cloud.
  2. Create an OAuth consent screen and configure your test user if the app is in testing mode.
  3. Create an OAuth Client ID with application type Web application.
  4. Add your GitHub Pages origin, for example https://cuhdyy.github.io, to Authorized JavaScript origins.
  5. Paste the OAuth Client ID and API key above, then save.
  6. Tap Connect Google and choose the Google account that manages your YouTube channel.

Google's consent screen may show an unverified-app warning while you test your own app. Only continue if you recognize your own project and understand the requested permissions.
